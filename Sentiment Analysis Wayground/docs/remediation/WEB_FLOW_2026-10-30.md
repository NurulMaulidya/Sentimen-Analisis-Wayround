# Penerapan struktur web SVM, TF-IDF dan aspek

Implementasi: 30–31 Oktober 2026. Verifikasi akhir: 31 Oktober 2026. Dasar: usulan struktur web yang disepakati setelah peninjauan dua PDF referensi. Perubahan diterapkan pada frontend, API dan tabel tambahan; model final, parameter penelitian, preprocessing bersama, dataset canonical, lexicon serta artefak evaluasi penelitian tidak diubah.

## Struktur dan alur yang diterapkan

Lima menu utama: Dashboard, Analisis Data Uji, Prediksi Satu Ulasan, Riwayat Analisis, Penelitian & Evaluasi. Setiap sesi upload memiliki navigasi Validasi & Data Awal → Preprocessing → TF-IDF → Labeling SVM → Analisis Aspek → Ringkasan, ditambah Evaluasi Upload bila ada label aktual valid. Tahap hilir dinonaktifkan jika prasyaratnya belum tersedia. Ringkasan juga menyediakan eksekusi seluruh alur sekaligus dan unduhan hasil.

## Aturan data dan metode

- Labeling SVM berarti **prediksi model**, berbeda dari label aktual dan label lexicon penelitian. Data upload tidak melatih model atau melakukan fit pada TF-IDF.
- Baris dengan label aktual kosong tetap dapat diprediksi. Label tidak dikenal ditolak sebelum sesi dibuat. Label kosong tidak dihitung dalam evaluasi; file tanpa label tetap dapat menyelesaikan analisis aspek.
- Baris sumber kosong dipertahankan pada tabel sumber, tetapi tidak dibuat sebagai ulasan pemrosesan. Deduplikasi mengikuti aturan yang ditampilkan: strip dan huruf kecil. Duplikat dipertahankan pada sumber, ditandai dan dikecualikan dari pipeline; jumlah duplikat belum diklaim sebelum deduplikasi dijalankan.
- Teks akhir kosong dan vektor TF-IDF tanpa fitur dikenal tidak diprediksi, bukan diberi netral otomatis. Jika semua ulasan tidak memiliki fitur dikenal, API menolak prediksi dan menampilkan penyebab. Ini perubahan kebijakan inferensi web yang disengaja; artefak model tetap sama. Untuk baris yang mempunyai fitur, hasil sama dengan pipeline final tersimpan.
- Jumlah kartu/grafik mencakup seluruh sesi, sedangkan filter/pagination berlaku pada tabel. Pada aspek, satu baris hasil per pasangan ulasan–aspek; keyword berulang tidak menambah hitungan pasangan. Satu ulasan boleh memiliki beberapa aspek.
- Deteksi aspek tetap berbasis keyword/kalimat pada teks asli, sedangkan sentimennya mengikuti label ulasan utuh. Halaman menjelaskan keterbatasan ini. Tidak ada klaim prediksi sentimen terpisah untuk masing-masing aspek atau probabilitas confidence yang belum dikalibrasi.
- Evaluasi penelitian tetap memakai 604 diagnostic holdout dengan paparan historis, bukan pristine test. Upload baru tidak mengganti metrik penelitian. Hasil tujuh eksperimen ditampilkan dengan lingkup metriknya; skor threshold terhadap label pakar tidak disamakan dengan grouped CV SVM.

## Penyimpanan dan migrasi

Empat tabel tambahan: `upload_rows`, `review_features`, `single_predictions`, `analysis_run_snapshots`. Tidak ada perubahan kolom pada tabel lama. Saat SQLite lama kekurangan tabel, startup membuat backup konsisten melalui SQLite backup API ke `data/backups/` sebelum `create_all`. Backup disertai metadata hash dan daftar tabel yang ditambahkan. Migrasi idempotent diuji dari schema sebelum stage 5 dan schema stage 5.

Setiap perubahan tahap hulu membatalkan hasil hilir. Jika sudah ada prediksi dengan identitas model tercatat, salinan ulasan/preprocessing, fitur, aspek dan evaluasi sebelumnya disimpan terlebih dahulu sebagai snapshot. Snapshot baru tersedia untuk rerun setelah penerapan fitur ini; hasil historis yang sebelumnya sudah tertimpa tidak direkonstruksi. Menghapus sesi juga menghapus snapshot terkait.

Riwayat lama tetap terbaca. Jika baris sumber dahulu tidak disimpan, UI menandainya sebagai sumber tidak lengkap, bukan mengarang isi baris kosong. Versi prediksi lama yang tidak tercatat tetap tidak diketahui. Detail bobot lama hanya tersedia bila memang disimpan; tidak dihitung ulang diam-diam memakai model berbeda.

Pengujian memakai database memory dan database legacy sementara. Database analisis pengguna tidak dipakai oleh fixture. Migrasi pada aplikasi utama terjadi ketika backend dengan kode baru dijalankan; server uji tidak menggantikan server pengguna.
