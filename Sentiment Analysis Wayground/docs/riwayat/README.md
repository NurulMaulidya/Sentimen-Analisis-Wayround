# Riwayat dokumentasi Wayground

Dokumen di sini mencatat konfigurasi, hasil, dan rencana pada tahap sebelumnya. Gunakan [peta proyek](../panduan_organisasi.md) dan [hasil penelitian aktif](../../README.md#hasil-penelitian-utama) untuk pekerjaan sekarang.

| Folder | Isi |
|---|---|
| [Audit](audit/) | Audit eksperimen, pipeline, dan kesesuaian metodologi. |
| [Penelitian](penelitian/) | Laporan proyek versi awal, evaluasi aspek lama, dan catatan perbaikan. |
| [Panduan](panduan/) | Panduan model dan diagnostik dari struktur sebelumnya. |

[Manifest pengelompokan](../remediation/MANIFEST_PENGELOMPOKAN_2026-11-10.json) mencatat nama asal, lokasi baru, dan SHA-256 dari berkas yang dipindahkan.
